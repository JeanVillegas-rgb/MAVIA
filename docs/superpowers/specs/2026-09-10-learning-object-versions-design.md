# Learning object versions: original, simplified, elaborated

Design date: 2026-09-10. Branch: `jean-latest`.

## Problem

Every learning object must be deliverable in three versions — original,
simplified, and elaborated. Today none of that happens usefully.

`generate_standalone_variants()` runs once, inside `publish_topic()`
(`backend/lessons/views.py:873`), and only for objects that are alone in their
group. Objects that semantic grouping has paired are excluded, and any variants
they previously had are deleted (`backend/course/variant_generator.py:156-159`).
Nothing else writes `LessonVariant`. A grouped object therefore ends up with one
version — its own text — and the group does no work for the learner: each member
is emitted as its own chunk by `_build_chunk()`, so a concept found in two PDFs
is taught twice.

The teacher never sees any of it. Publish generates the text and sets
`published = True` in the same request, regardless of generation errors, so
machine-authored narration reaches students unreviewed.

`LearningObjectGroup` already anticipates the missing piece: it "deliberately
carries no difficulty or remediation label. Those decisions belong to the
learning-path component that consumes the group." This document specifies that
decision.

## Decisions

These were settled during design and are not open for re-litigation in the
implementation plan.

1. **Fixed triple.** Every learning object presented to a student has exactly
   three slots: original, simplified, elaborated.
2. **Surplus is kept, not discarded.** Versions beyond the three are stored as
   extras. The interaction pipeline may consume them later.
3. **The group supplies the versions.** When objects are grouped, their member
   texts are the versions. The earliest-uploaded member is the original.
4. **The LLM fills only what real material cannot.** A standalone object gets
   both simplified and elaborated from Gemma. A pair supplies one real
   alternate; Gemma fills the one remaining slot. A triple fills all three from
   real text and calls no LLM.
5. **Absorbed members are flagged, not destroyed.** A member represented by
   another keeps its row, `metadata_id`, and question links.
6. **Assignment is proposed, not decided.** A heuristic pre-fills the
   simplified/elaborated assignment; ambiguous cases are routed to the teacher.
7. **This runs at review, not publish.** Publish becomes a commit of
   already-approved content.

## Data model

Three additions. No destructive migration; no existing column changes meaning.

### `LearningObject.represented_by`

Nullable self-referential foreign key, `on_delete=SET_NULL`.

- `NULL` — this object is a teaching step.
- Set — this object is still a record, but the lesson teaches it through the
  referenced object.

This is the only field written when a group is collapsed. It is reversible by
clearing it.

### `LessonVariant.variant`

The existing `variant` field carries `ELABORATED` / `SIMPLIFIED`. Add `EXTRA`.
The field keeps its current name; "slot" is used in prose below to mean one of
its values.

`unique_together = ("learning_object", "variant")` cannot hold once extras
exist, because an object may have several. Replace it with a
`UniqueConstraint` conditioned on `variant != "EXTRA"`, so the three primary
slots stay single-occupancy while extras are unconstrained.

No `ORIGINAL` row is stored. The original is the representative object's own
`content`, which `_build_chunk()` already emits as `normal`. Storing it would
duplicate the source of truth.

### `LessonVariant` provenance

- `origin` — `source_pdf` or `generated`.
- `source_learning_object` — nullable FK; for `source_pdf` rows, which object
  supplied the text.
- `assigned_by` — `heuristic` or `teacher`.

Provenance is required, not decorative. It is what lets the review UI say where
a rung came from, lets an ungroup delete generated rows while keeping human
ones, and lets the thesis distinguish human-written rungs from machine-written
ones.

`QuestionLearningObjectLink` and `PrerequisiteEdge` are unchanged.

## Assignment

For each confirmed group in a topic:

1. **Order members** by their material's `created_at`. The earliest is the
   representative; its content is the original.
2. **Classify each remaining member** into simplified or elaborated using the
   heuristic below, comparing it against the representative.
3. **Resolve collisions.** If two members claim the same slot, the one with the
   larger margin takes it; the other becomes an extra.
4. **Fill gaps.** Any of the two slots still empty is generated by Gemma from
   the representative's content, using the existing grounded prompt and its
   word-count limits.
5. **Flag.** Every non-representative member gets `represented_by` set to the
   representative.

A standalone object is the degenerate case: it is its own representative, has
no members to classify, and both slots are generated.

**When generation fails.** `VariantGenerationError` is raised on invalid JSON,
empty or identical output, and word-count overruns, and it is per-object rather
than fatal. A failed slot stays empty and is surfaced in the review screen as an
incomplete chunk with its error, alongside a retry. It is never filled silently
and never treated as confirmed. Whether an incomplete chunk blocks publish is
left to the implementation plan; the requirement here is that the teacher sees
it before publish rather than discovering it in the response payload afterward,
which is the current behaviour.

Objects with empty content remain excluded, as today. Image objects are
in scope — two of the current course's objects are vision-model narrations and
one of the six groups pairs them — but see Risks.

## Classification heuristic

Two signals, computed on the two texts being compared:

- **Flesch-Kincaid grade level.** One number capturing sentence length and
  syllable complexity. Computed locally; no new heavy dependency, no network.
- **Word count.**

Measured on the six real pairs in the current course, the two signals agreed on
direction in all six, and Flesch-Kincaid added no discrimination over word count
alone. They are kept together only so that disagreement can be detected and used
as a veto.

**Automatic assignment requires all four:**

- `ΔFK > 1.5`
- word ratio `≥ 1.25`
- `ΔWords > 10`
- both signals point the same direction

Anything else is routed to the teacher, pre-filled with the heuristic's best
guess. Direction disagreement routes to the teacher regardless of magnitude:
a text can be longer and simpler at once, and that is exactly the case where a
guess is least defensible.

The word ratio is carried alongside the absolute word difference deliberately.
The absolute threshold does not travel — ten words is about a quarter of a
50-word object and 2.5% of a 400-word one — while the ratio is scale-free.
Requiring both keeps the gate conservative for now.

On current data this classifies two of six pairs automatically:

| group | ΔFK | ΔWords | ratio | verdict |
|-------|-----|--------|-------|---------|
| 277 | 0.2 | 6 | 1.12 | teacher |
| 278 | 1.0 | 4 | 1.11 | teacher |
| 279 | 0.9 | 22 | 1.69 | teacher |
| 280 | 3.4 | 17 | 1.46 | automatic |
| 281 | 2.1 | 13 | 1.35 | automatic |
| 286 | 1.9 | 9 | 1.26 | teacher |

These are operating thresholds, not calibrated values. They are chosen to be
conservative while the grouping that feeds them is itself unvalidated. They
should be revisited once more courses have been reviewed.

### Why not a classifier

A classifier would have to be defended with labelled data — teachers marking
which of two texts is simpler, across enough pairs to report precision. But a
course this size produces six such decisions. Building and validating a model to
avoid six confirmations inverts the cost. A teacher-confirmed label needs no
calibration, and a wrong heuristic guess is caught in the two seconds before it
is saved rather than silently shipped.

This trade changes if MAVIA is ever meant to run without teacher review. That
is a different product.

## Where it runs

Assignment moves out of `publish_topic()` and into the review step, next to the
existing learning-object confirmation.

The teacher sees, per chunk, the three versions with their provenance, and
confirms or corrects the simplified/elaborated assignment. Ambiguous pairs are
presented as an explicit either/or rather than a pre-made choice.

`publish_topic()` keeps calling generation, but by then every assignment is
confirmed and every gap filled, so the call is a no-op in the normal case. It
remains as a backstop for content edited after review.

This closes a gap that exists today independently of this design: learning
objects and questions both have confirmation steps, and the narration students
actually read has none.

## Consumers

`_build_chunk()` filters to `represented_by IS NULL`. The current course's 69
objects render as 63 chunks; each grouped chunk carries three versions, two of
them written by a teacher.

The prerequisite graph treats represented objects as skipped, resolving edges
that touch them to their representative. That resolution belongs to
`learning_path`, which is not wired on this branch and is deliberately out of
scope here.

Question links are untouched. An absorbed object's questions were generated from
text that is now a rung of the surviving chunk, which makes them more useful,
not less.

## Reversibility

When a teacher ungroups:

- Clear `represented_by` on the released member.
- Delete `origin = generated` rows for the affected objects.
- Keep `origin = source_pdf` rows.

Both objects become teaching steps again and no human-written text is lost.
Regenerating the machine rungs is one Gemma call each.

This is the property that justifies flagging over deletion. Grouping is an
automatic decision made at an uncalibrated threshold; one of the six current
groups ("Everyday Examples" paired with "Changes of State") looks like a false
positive. Under this design that costs a flag flip.

## Testing

- **Heuristic:** each gate independently; direction disagreement vetoes
  regardless of magnitude; symmetry (comparing A to B and B to A agree).
- **Assignment:** standalone generates two; pair generates one; triple generates
  none; four or more produce extras; slot collisions resolve by margin.
- **Representative choice:** earliest material `created_at` wins; ties broken
  deterministically.
- **Reversibility:** ungroup clears the flag, deletes generated rows, preserves
  source rows and question links.
- **Package:** represented objects are absent from chunks; every emitted chunk
  has three slots or a recorded reason it does not.
- **No silent LLM calls:** generation is not invoked for a group that real text
  already fills.

Fixtures should use the six real pairs, which cover clear gaps, thin gaps, and
a probable false grouping.

## Non-goals

- The adaptive escalation ladder in `backend/adaptive/services.py`. It hardcodes
  `NORMAL → ELABORATED → SIMPLIFIED` and escalates by index without checking
  what a chunk contains. Out of scope by explicit decision; to be adjusted with
  the interaction pipeline.
- Wiring `learning_path` into `INSTALLED_APPS`. Deferred until learning-object
  content is settled.
- Calibrating the `0.60` grouping threshold.
- Audio for the new rungs.

## Risks

**The upstream grouping is unvalidated.** Assignment inherits whatever grouping
produces. `auto_threshold_source` is `configured_default`; no labelled
evaluation exists. This design mitigates the consequence — wrong groups are
reversible — but does not address the cause.

**Readability of machine-written text.** One of the six pairs is two
vision-model narrations. Their Flesch-Kincaid scores describe Gemma's phrasing,
not a teacher's intent. Whether image objects should participate in
difficulty ranking at all is worth revisiting once there is more data.

**The corpus reads above its audience.** Measured grade levels across the
current Grade 1 course run 5.1 to 10.5. That is an argument for having a
simplified rung, and also a signal that extraction may be producing text above
the target audience — a separate finding, recorded here because it was
discovered during this work.

**Short texts weaken the signal.** Every object is three or four sentences.
Statistical readability measures are noisy at that length, which is the reason
the gate is conservative and the teacher is the tiebreak.
